# Personal-Ledger-System 个人记账本Web系统

## 项目概述

本项目旨在开发一款简洁易用的个人记账 Web 系统，帮助用户高效记录日常收支、清晰掌握资金流向、养成理性消费习惯。系统面向需要个人财务管理的普通用户（如学生、上班族），提供从账目记录、分类统计到可视化报表的一站式服务。

## 核心功能模块

### 用户管理

#### 账号注册

- 支持手机号或者邮箱两种注册渠道，实时校验格式合法性
- 密码强度校验，要求 8-16 位，包含数字加字母组合，避免弱密码风险
- 注册验证码校验，如图形验证码、短信、邮箱验证码可选，防范恶意批量注册
- 自动校验账号唯一性，重复注册给出明确提示

#### 账号登录

- 支持密码 / 验证码两种登录方式
- 支持 7 天免登录配置，退出登录后自动失效所有凭证
- 连续 5 次登录失败触发账号临时锁定，防范暴力破解

#### 账号安全操作

- 支持安全退出登录，自动清除客户端与服务端的登录态
- 忘记密码：通过绑定的手机号或者邮箱接收验证码，免旧密码重置登录密码
- 账号注销：支持用户主动注销账号，注销后 7 天内可恢复，到期后永久清除所有关联账目数据

#### 个人信息 & 个性化配置

- 基础信息修改：自定义昵称、上传个人头像、更换绑定手机号或者邮箱
- 安全设置：修改登录密码、开启 Web 端二次验证密码
- 记账个性化配置：设置每月消费预算阈值、自定义收支分类偏好、设置报表默认展示周期

## 技术栈

* **前端**: HTML + CSS + JavaScript
* **后端**: Spring Boot / Python Flask
* **数据库**: MySQL
* **版本控制**: Git + GitHub

\## 核心功能模块

\### ① 用户管理

支持用户注册、账号登录、退出登录，以及个人信息维护(如昵称、密码修改)。

\### ④ 数据统计与图表展示

系统自动生成月度/年度收支汇总，并通过柱状图、饼图等可视化形式展示支出分类占比及收支趋势。

\### ⑤ 分类管理

预设餐饮、交通、购物、娱乐等常用分类，用户可自行添加、编辑或删除自定义分类，满足个性化记账需求。
