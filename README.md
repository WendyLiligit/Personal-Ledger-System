# Personal-Ledger-System 个人记账本Web系统

## 项目概述
本项目旨在开发一款简洁易用的个人记账 Web 系统，帮助用户高效记录日常收支、清晰掌握资金流向、养成理性消费习惯。系统面向需要个人财务管理的普通用户（如学生、上班族），提供从账目记录、分类统计到可视化报表的一站式服务。

## 核心功能模块
### ① 用户管理
支持用户注册、账号登录、退出登录，以及个人信息维护(如昵称、密码修改)。

### ② 收支记录管理
用户可添加、修改、删除每一笔收入或支出记录，记录内容包含金额、类型(收入/支出)、分类、日期及备注。

### ③ 多维度查询与筛选
支持按日期范围、收支分类、金额区间等条件进行组合查询，方便用户快速定位历史记录。

### ④ 数据统计与图表展示
系统自动生成月度/年度收支汇总，并通过柱状图、饼图等可视化形式展示支出分类占比及收支趋势。

### ⑤ 分类管理
预设餐饮、交通、购物、娱乐等常用分类，用户可自行添加、编辑或删除自定义分类，满足个性化记账需求。

## 技术栈
- **前端**: HTML + CSS + JavaScript
- **后端**: Spring Boot / Python Flask
- **数据库**: MySQL
- **版本控制**: Git + GitHub
