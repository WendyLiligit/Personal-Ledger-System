# Personal-Ledger-System 个人记账本Web系统

## 项目概述

本项目旨在开发一款简洁易用的个人记账 Web 系统，帮助用户高效记录日常收支、清晰掌握资金流向、养成理性消费习惯。系统面向需要个人财务管理的普通用户（如学生、上班族），提供从账目记录、分类统计到可视化报表的一站式服务。

## 核心功能模块

###  用户管理

- 支持用户注册、账号登录、退出登录
- 支持个人信息维护：昵称修改、密码修改

### 收支记录管理

- 支持收入 / 支出记录的添加、修改、删除
- 记录包含：金额、类型（收入 / 支出）、分类、日期、备注

###  多维度查询与筛选

- 支持按日期范围查询
- 支持按收支分类筛选
- 支持按金额区间筛选
- 支持多条件组合查询，快速定位历史记录

###  数据统计与图表展示

- 自动生成月度、年度收支汇总
- 以柱状图、饼图可视化展示：
- 支出分类占比
- 收支趋势对比

###  分类管理

- 预设常用分类：餐饮、交通、购物、娱乐等
- 支持用户自定义添加、编辑、删除分类

## 技术栈

* **前端**: HTML + CSS + JavaScript
* **后端**: Spring Boot / Python Flask
* **数据库**: MySQL
* **版本控制**: Git + GitHub
